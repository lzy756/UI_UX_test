# personal-blog

## 项目简介

一个基于 React + Vite 的个人博客前端页面示例，用于展示文章列表、侧边栏与页脚布局。

## 技术栈

- React 18
- Vite 5
- CSS

## 目录结构

- `src/`：前端源码
  - `components/`：页面组件
  - `App.jsx`：页面入口组件
  - `main.jsx`：应用启动入口
- `index.html`：HTML 模板

## 快速开始

```bash
npm install
npm run dev
```

## 构建与预览

```bash
npm run build
npm run preview
```

## 说明

页面数据为本地静态示例数据，适合作为 UI 原型或样式参考。
