# personal-blog

## 项目简介

一个基于 React + Vite 的个人博客前端页面示例，涵盖头部导航、Hero 区、文章卡片列表、标签侧栏以及页脚社交链接等常见模块，可作为博客/作品集的 UI 参考或快速原型。

**仓库定位**
- 展示简洁、现代的博客首页布局
- 提供可复用的卡片、侧栏等组件骨架
- 适合作为个人站点的样式示例或设计稿落地模板

## 技术栈

- React 18
- Vite 5
- CSS

## 目录结构

- `src/`：前端源码
  - `components/`：页面组件
  - `App.jsx`：页面入口组件
  - `main.jsx`：应用启动入口
- `index.html`：HTML 模板

## 快速开始

```bash
npm install
npm run dev
```

## 构建与预览

```bash
npm run build
npm run preview
```

## 说明

页面数据为本地静态示例数据，适合作为 UI 原型或样式参考。
